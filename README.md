
# EnneSG – Sito Statico

Struttura cartelle:
- `/index.html`
- `/servizi.html`
- `/iso.html`
- `/sicurezza.html`
- `/contatti.html`
- `/clienti.html`
- `/privacy.html`
- `/css/style.css`
- `/img/hero-ennesg.jpg` (da aggiungere)
- `/img/og-ennesg.jpg` (da aggiungere)

## Come usare
1. Carica tutti i file su GitHub (branch `main`).  
2. Aggiungi le immagini:
   - `img/hero-ennesg.jpg` → usa il banner orizzontale (consigliato 1920×600).
   - `img/og-ennesg.jpg` → immagine Open Graph 1200×630.
   - `favicon.ico` → icona del sito (puoi usare la versione SG).
3. Attiva GitHub Pages (Impostazioni → Pages → Source: `main` /root).

I contatti sono già inseriti in footer e nella pagina contatti.
